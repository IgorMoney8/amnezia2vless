# amnezia2vless
Скрипт генерирует ключ формата vless:// из .json-файла "оригинального формата XRay". Ключ корректно распознаётся в nekobox, v2rayN(G), Streisand, V2Box и прочих xray/sing-box клиентах.

## 1. Установите Python
На Windows вы можете установить Python 3.13 или выше через Microsoft Store или воспользоваться сайтом разработчика: https://www.python.org/downloads/windows/

На Debian / Ubuntu / Mint:
```bash
sudo apt install python3
```

## 2. Загрузите скрипт:

```bash
curl -o amnezia2vless.py https://raw.githubusercontent.com/vrzdrb/amnezia2vless/blob/main/amnezia2vless
```
или
```bash
wget https://raw.githubusercontent.com/vrzdrb/amnezia2vless/main/amnezia2vless
```

## 3. Запустите скрипт:
```bash
python3 amnezia2vless.py
```
